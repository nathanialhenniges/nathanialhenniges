# Hi, I’m Nathanial

I’m a software developer and creator in Wisconsin. I build web apps, open-source
tools, and WordPress sites as President of [MrDemonWolf, Inc.](https://github.com/MrDemonWolf),
a small studio focused on web development, software, and hosting for small
businesses. I’m also Co-Founder and Founding Engineer at [Kommit](https://getkommit.ai).

Outside of work, I stream, make music, and build community projects as
[MrDemonWolf](https://mrdemonwolf.com).

## What I’m building ![GitHub Octicon: code](./icons/code.svg)

- [Dirework](https://github.com/MrDemonWolf/dirework) — a co-working timer,
  viewer task list, Twitch bot, and OBS overlays.
- [WolfWave](https://github.com/MrDemonWolf/wolfwave) — a macOS app that connects
  Apple Music with Twitch, Discord, and OBS.
- [Linkden](https://github.com/MrDemonWolf/linkden) — a self-hosted link-in-bio
  platform built for Cloudflare.
- [ConPaws](https://github.com/MrDemonWolf/conpaws) — an offline-friendly
  convention companion for schedules, meetups, and friends.
- [Minimal Pomo Timer](https://github.com/nathanialhenniges/Minimal-Pomo-Timer) —
  a small focus timer project.
